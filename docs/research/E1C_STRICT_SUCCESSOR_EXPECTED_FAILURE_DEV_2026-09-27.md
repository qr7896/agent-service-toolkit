## Single generic mechanism

EFIL changes only the reproducer interpretation/compilation layer.

1. Extract the last explicit exception type and message from issue-visible natural language or traceback. No test patch, Gold, grader, task-id feature, historical answer, or official failure assertion is allowed.
2. Parse an issue-visible Python scenario. Lift only deterministic top-level import and from-import bindings into an importlib prelude generated by the runner. Relative imports, star imports, nested imports, duplicate bindings, ambiguous dotted imports without aliases, unsafe body syntax, network access, dunder access, dynamic execution, and filesystem reads fail closed.
3. Validate the import-free body with the existing strict WitnessIR safety validator. The validator is not loosened.
4. On exact-base plus immutable official image plus network none, a nonzero exit is a trusted reproducer only when the final observed exception type and normalized message exactly match the public issue contract. Import, setup, and environment errors remain negative evidence. Exit 0 means the documented semantic failure was not reproduced.

This separates invalid scenario execution from a valid buggy-base semantic failure, as required by PLAYBOOK Stage D.
